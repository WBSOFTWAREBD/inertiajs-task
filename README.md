# Laravel + Inertia.js — Interview Task

## Objective

Build a small **E-Commerce application** using:

* Laravel 13
* Inertia.js
* React
* MySQL

## 1. Authentication

Implement separate authentication for:

* Admin
* User

Both panels should have protected routes.

## 2. Admin Panel

Create an Inertia-based Admin Panel with:

* Dashboard
* Category CRUD
* Product CRUD
* Order list
* Order details

Each product should belong to a category and contain basic information such as:

* Name
* Price
* Description

## 3. Frontend

Create an Inertia-based frontend where users can:

* View products
* Filter products by category
* View product details
* Add products to cart
* Update cart items
* Remove cart items

## 4. Checkout

Users should be able to proceed to checkout from the cart.

If the user is not logged in, they must be redirected to the **Login/Register** page before proceeding.

After successful authentication, the user should be able to place an order.

> No real payment gateway is required.

## 5. My Purchases

Logged-in users should be able to:

* View their previous orders
* View order details
* See purchased products
* See quantities and prices
* See the total order amount

Users should only be able to access their own orders.

## Requirements

The project must use:

* **Laravel 13**
* **Inertia.js**
* **React**
* **MySQL**
* **Eloquent Relationships**
* **Proper Validation**
* **Authentication & Authorization**

### Focus

Focus on **functionality, backend logic, database relationships, authentication, and clean Inertia/React implementation** rather than advanced UI design.

### Expected Completion Time

**4–5 Hours**
