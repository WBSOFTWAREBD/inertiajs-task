Laravel + Inertia.js — Interview Task
Objective
Build a small E-Commerce application using Laravel 13, Inertia.js, React, and MySQL.
1. Authentication
Implement separate authentication for:
Admin
User
Both panels should have protected routes.
2. Admin Panel
Create an Inertia-based Admin Panel with:
Dashboard
Category CRUD
Product CRUD
Order list and order details
A product should belong to a category and contain basic information such as name, price, and description.
3. Frontend
Create an Inertia-based frontend where users can:
View products
Filter products by category
View product details
Add products to cart
Update/remove cart items

4. Checkout
Users can proceed to checkout from the cart.
If the user is not logged in, they must be redirected to Login/Register before proceeding.
After authentication, the user should be able to place an order.
No real payment gateway is required.
5. My Purchases
Logged-in users should be able to:
View their previous orders
View order details
See purchased products, quantities, prices, and total
Users should only be able to access their own orders.
Requirements
Use:
Laravel 13
Inertia.js
React
MySQL
Eloquent relationships
Proper validation and authentication
Focus on functionality, backend logic, database relationships, and clean Inertia/React implementation rather than advanced UI.
Expected completion time: 4–5 hours.
